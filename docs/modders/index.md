# Modder documentation

ThedasIO imports Dragon Age: Origins models into Blender and exports them back as standalone files.

Set the game folder once in the add-on preferences (ThedasIO section, Game folder). The panels live in the ThedasIO tab.

## How-to guides

- [Importing](importing.md): pull a model from the game database or a file on disk, and scan the archives.
- [Exporting](exporting.md): write loaded resources back to a folder, and check a model before export.
- [Animation](animation.md): play a `.ani` on a model, edit its keys, and export it.
- [Collision](collision.md): turn on PHY support, edit collision shapes, and add a capsule to a bone.
- [Substance Painter round trip](substance.md): paint textures in Substance and bring them back.
